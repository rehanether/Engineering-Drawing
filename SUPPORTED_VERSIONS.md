# Supported Versions

EngineeringDrawing.io is under active development. We recommend using the latest release to receive new features, bug fixes, performance improvements, and security updates.

## Support Policy

| Version | Supported | Security Updates |
|---------|-----------|------------------|
| Latest Release | ✅ Yes | ✅ Yes |
| Previous Release | ⚠️ Limited | ⚠️ Critical fixes only |
| Older Versions | ❌ No | ❌ No |

## Browser Support

EngineeringDrawing.io is tested with:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

For the best experience, use the latest version of your browser.

## Platform Support

- Windows 10/11
- macOS
- Linux
- Android
- iOS

## Blockchain Support

EngineeringDrawing.io currently supports:

- BNB Smart Chain (BSC)
- BEP-20 Tokens
- MetaMask
- WalletConnect-compatible wallets

Additional blockchain support may be added in future releases.
