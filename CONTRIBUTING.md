# Contributing to EngineeringDrawing.io

Thank you for your interest in contributing to EngineeringDrawing.io.

We welcome contributions from developers, engineers, researchers, designers, and the open-source community.

## How to Contribute

1. Fork this repository.
2. Create a new feature branch.
3. Make your changes.
4. Test your changes.
5. Commit using clear commit messages.
6. Submit a Pull Request.

## Coding Standards

- Follow JavaScript and React best practices.
- Write clean and documented code.
- Keep commits small and meaningful.
- Update documentation when adding new features.

## Reporting Issues

If you discover a bug, please create a GitHub Issue with:

- Description
- Steps to reproduce
- Expected behavior
- Screenshots (if applicable)

## Feature Requests

Ideas for improving AI-powered industrial engineering are always welcome.
